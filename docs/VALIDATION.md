# 发布验证

本仓库 CI 使用 Node.js 24 和 Linux amd64，从提交源码执行：

- 后端 `npm ci --ignore-scripts && npm run test:rewards-fixes`，覆盖搜索配额读取、超时、迟到入账、未完成失败传递、积分去重及会话初始化等路径。
- 面板 `npm test`，覆盖账号结果、历史积分和补跑策略。
- Shell 语法和 Compose 解析。
- 两个 Dockerfile 从公开基础镜像构建，不依赖维护者私有基础镜像。
- 无真实账号、无定时计划启动，检查本地 API、面板及鉴权连接。
- Chromium 加载内存 HTML 页面和 impit 原生模块导入，不请求微软账号。

每次准确结果见仓库 Actions 的对应提交。首次独立发布以通过的 CI 运行和 Release 校验文件为准，未通过的检查不会视为已验证。

本地维护版在导出前的 2026-11-23 修复中已有后端 110 项、面板 52 项离线测试通过记录；独立打包仍重新运行，不以历史结果代替当前检查。

不包含真实账号积分获取验收、ARM 架构验收或所有代理／地区配置验收；这些需要实际部署环境和明确授权。
